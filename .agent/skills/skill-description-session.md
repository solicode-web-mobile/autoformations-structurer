# Skill — Rédaction de description de Session

## 1. Objectif

Produire une **description simple, claire et compacte d’une Session** à partir de sa structure validée.

La description doit permettre à l’apprenant de comprendre :

**ce que j’apprends → ce que je cherche → ce que je construis → ce que j’intègre dans le Projet fil rouge.**

Une **Session est un Sprint de réalisation du Projet fil rouge**.

## 2. Entrées

Utiliser uniquement les éléments validés :

* **Session** : code et titre.
* **UA** et titres des chapitres.
* **Labs**.
* **Prototype**.
* **Projet fil rouge**.
* **Veille technologies**.
* **Sprint Projet fil rouge**, lorsqu’il est fourni.

Ne jamais modifier, fusionner, supprimer ou renommer ces éléments.

## 3. Principe

La présentation suit le parcours de l’apprenant :

**J’apprends → Je cherche → Je construis → J’intègre**

Le **Projet fil rouge** donne le contexte de la Session.

Les **UA** présentent les apprentissages.

Les **Labs** permettent de chercher, observer et expérimenter.

Le **Prototype** permet de construire une première réalisation.

Le **Projet fil rouge** permet de réutiliser les acquis dans une réalisation réelle.

La **Veille technologies** présente les technologies ou évolutions utiles à la Session.

## 4. Règles de rédaction

* Utiliser un français simple.
* Faire des phrases courtes.
* Décrire le résultat attendu.
* Relier les activités à la réalisation.
* Ne pas ajouter de notion absente des données fournies.
* Ne pas transformer une Session en cours théorique.
* Garder une présentation courte et directement compréhensible.

## 5. Structure obligatoire

```markdown
# [Code] — [Titre de la Session]

**Objectif**  
[Ce que l’apprenant doit savoir faire à la fin de la Session.]

**Sprint Projet fil rouge**  
[Ce que l’apprenant réalise dans le Projet fil rouge pendant la Session.]

## UA et chapitres
[UA et titres des chapitres.]


## Labs
[Travaux de recherche, observation et expérimentation.]

## Veille technologies
[Technologies ou évolutions à découvrir.]

## Prototype
[Ce que l’apprenant réalise pour mettre en pratique les acquis.]


## Projet fil rouge
[Ce que l’apprenant réalise ou ajoute dans le Projet fil rouge.]
```

## 6. Résultat attendu

La description finale doit permettre à l’apprenant de comprendre rapidement :

**Pourquoi je fais cette Session → ce que j’apprends → ce que je réalise → ce que j’ajoute au Projet fil rouge.**
