# Skill — Rédaction du Prototype et du Projet Fil Rouge

## 1. Objectif

Produire les contenus pédagogiques nécessaires à la réalisation du **Prototype** et du **Projet Fil Rouge** d’un Sprint ou d’une Session.

Le contenu doit transformer les **UA, compétences, objectifs et réalisations attendues** en travaux pratiques cohérents avec le niveau de l’apprenant.

## 2. Entrées

Utiliser :

* la **Session validée** ;
* la **Vision horizontale** ;
* le **Sprint** concerné ;
* les **UA** ;
* les compétences mobilisées ;
* les prérequis ;
* les notions acquises ;
* la réalisation attendue ;
* le contexte et les fonctionnalités du **Projet Fil Rouge**.

Ne jamais modifier les éléments pédagogiques validés.

## 3. Distinction pédagogique

Le **Prototype** sert à **adapter et expérimenter** les acquis dans une nouvelle situation proche du tutoriel.

Le **Projet Fil Rouge** sert à **transposer et réutiliser** les acquis dans le projet réel.

**Prototype :**
**J’ai compris → J’adapte → Je réalise.**

**Projet Fil Rouge :**
**J’ai appris → Je réutilise → J’intègre au projet.**

## 4. Principe de progression

Respecter :

**Tutoriel → Prototype → Projet Fil Rouge**

Le Prototype ne doit pas être une simple copie du tutoriel.

Le Projet Fil Rouge ne doit pas introduire une nouvelle notion non préparée.

Chaque travail doit réutiliser les acquis des UA précédentes.

## 5. Structure obligatoire

```markdown
# [Type] — [Titre]

## 1. Objectif

[Ce que l’apprenant doit réaliser.]

## 2. Contexte

[Situation simple et concrète.]

## 3. Travail à faire

### Étape 1 — [Action]
[Consigne.]

### Étape 2 — [Action]
[Consigne.]

### Étape 3 — [Action]
[Consigne.]

## 4. Fonctionnalités attendues

- [Fonctionnalité 1]
- [Fonctionnalité 2]
- [Fonctionnalité 3]

## 5. Résultat attendu

[Description du résultat final observable.]

## 6. Livrable

[Ce que l’apprenant doit remettre.]

## 7. Critères de réussite

- [Critère 1]
- [Critère 2]
- [Critère 3]
```

## 6. Rédaction du Prototype

Le Prototype doit :

* réutiliser les notions récemment apprises ;
* proposer un contexte différent du tutoriel ;
* demander une adaptation limitée ;
* guider suffisamment l’apprenant ;
* vérifier la compréhension par la réalisation.

Le Prototype doit être **plus ouvert que le tutoriel**, mais rester accessible.

Éviter de donner tout le code.

Privilégier :

> **Objectif → Consignes → Contraintes → Résultat attendu**

## 7. Rédaction du Projet Fil Rouge

Le Projet Fil Rouge doit :

* s’intégrer au projet réel ;
* réutiliser les acquis du Sprint ;
* produire une fonctionnalité réellement exploitable ;
* favoriser la réutilisation des compétences ;
* rester cohérent avec l’architecture existante du projet.

Ne pas transformer le travail en tutoriel détaillé.

L’apprenant doit chercher, décider et réaliser à partir des acquis validés.

## 8. Niveau d’accompagnement

Respecter progressivement :

**Tutoriel : accompagnement fort**
**Prototype : accompagnement moyen**
**Projet Fil Rouge : accompagnement réduit**

Le niveau d’aide doit diminuer pour favoriser l’autonomie.

## 9. Lien avec les UA

Chaque réalisation doit mobiliser clairement les **UA concernées**.

Avant de rédiger, vérifier :

**UA → notions → capacité → tâche → résultat**

Ne pas demander une tâche qui nécessite une compétence non encore acquise ou prévue comme prérequis.

## 10. Travail à faire

Les consignes doivent être :

* concrètes ;
* courtes ;
* exécutables ;
* vérifiables ;
* adaptées au niveau de l’apprenant.

Utiliser des verbes d’action :

> Créer · Ajouter · Modifier · Intégrer · Tester · Vérifier · Présenter

## 11. Critères de réussite

Les critères doivent permettre à l’apprenant et au formateur de vérifier rapidement le résultat.

Privilégier des critères observables :

> La fonctionnalité fonctionne.
> Les données sont correctement affichées.
> Le formulaire est fonctionnel.
> Le résultat respecte la maquette.

Éviter les critères vagues :

> Le travail est bien réalisé.

## 12. Contrôle qualité

Avant de finaliser, vérifier :

* cohérence avec les UA ;
* cohérence avec le Sprint ;
* cohérence avec le niveau N1 ;
* progression Tutoriel → Prototype → Projet Fil Rouge ;
* absence de nouvelle notion non préparée ;
* difficulté adaptée ;
* consignes compréhensibles ;
* résultat observable ;
* livrable concret ;
* critères mesurables ;
* cohérence avec le Projet Fil Rouge ;
* français **A1–A2**.

## 13. Règle fondamentale

> **Le Prototype transforme l’apprentissage en capacité d’adaptation ; le Projet Fil Rouge transforme cette capacité en réalisation professionnelle intégrée au projet réel.**
