# 📘 Chapitre 5 – Les tableaux en JavaScript (sans DOM)

## 1. 🎯 Objectif pédagogique

À la fin de ce chapitre, l’apprenant sera capable de :

- Créer, lire et modifier un tableau JavaScript ;
- Ajouter ou supprimer des éléments ;
- Parcourir un tableau à l’aide de boucles et de méthodes intégrées ;
- Manipuler un tableau d’objets pour stocker des données structurées ;

## 2. 📚 Concepts abordés

- Structure d’un tableau et indexation à partir de 0

- Boucles : `for`, `for...of`, `forEach`

- Tableaux d’objets

## 3. 🧠 Explication théorique

### 3.1 Qu’est-ce qu’un tableau ?

Un **tableau** est une structure de données ordonnée permettant de stocker plusieurs valeurs dans une seule variable.

```js
let fruits = ["pomme", "banane", "cerise"];
console.log(fruits[0]); // pomme
console.log(fruits[2]); // cerise
```

Chaque élément possède un indice commençant à 0.
Ici : fruits[0] = "pomme" et fruits.length = 3.

### 3.2 Créer un tableau

Deux syntaxes sont possibles :

```js
// 1. Syntaxe littérale (la plus utilisée)
let notes = [12, 14, 16];

// 2. Avec le constructeur Array
let couleurs = new Array("Rouge", "Vert", "Bleu");
```

### 3.3 Accéder et modifier les éléments

Chaque élément se lit ou se modifie via son index :

```js
let animaux = ["Chat", "Chien", "Lapin"];
animaux[1] = "Cheval";
console.log(animaux); // ["Chat", "Cheval", "Lapin"]
```

### 3.4 La propriété length

Elle donne la taille du tableau :

```js
let nombres = [10, 20, 30, 40];
console.log(nombres.length); // 4
```

### 3.5 Parcourir un tableau

Boucle for classique :

```js
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
```

Boucle for...of :

```js
for (let fruit of fruits) {
  console.log(fruit);
}
```

Méthode forEach :

```js
fruits.forEach(function (item, index) {
  console.log(index + " → " + item);
});
```

### 3.5 Méthodes de manipulation de tableaux

Méthode Action Exemple

- push() Ajoute un élément à la fin fruits.push("Mangue")
- pop() Supprime le dernier élément fruits.pop()
- unshift() Ajoute un élément au début fruits.unshift("Fraise")
- shift() Supprime le premier élément fruits.shift()
- splice(i, n) Supprime ou remplace fruits.splice(1, 1)
- slice(a, b) Copie une partie fruits.slice(0, 2)
- indexOf() Retourne l’index d’un élément fruits.indexOf("Orange")
- includes() Vérifie la présence fruits.includes("Pomme")

### 3.6 Tableaux multidimensionnels

Un tableau peut contenir d’autres tableaux :

```js
let notesEleves = [
  ["Ali", 12, 15],
  ["Sara", 18, 17],
  ["Omar", 10, 11],
];

console.log(notesEleves[1][0]); // "Sara"
console.log(notesEleves[2][1]); // 10
```

### 3.7 Les tableaux d’objets

Un tableau d’objets permet de regrouper plusieurs entités ayant les mêmes propriétés.
C’est une structure très utilisée dans les projets réels (gestion d’utilisateurs, produits, etc.).

Exemple simple :

```js
let utilisateurs = [
  { nom: "Alice", age: 25 },
  { nom: "Bob", age: 30 },
  { nom: "Charlie", age: 22 },
];
```

Accès aux propriétés :

```js
console.log(utilisateurs[0].nom); // Alice
console.log(utilisateurs[2].age); // 22
```

Parcours d’un tableau d’objets :

```js
utilisateurs.forEach(function (user) {
  console.log(user.nom + " a " + user.age + " ans");
});
```

## 4. 🛠 Tutoriel pratique

Objectif
Mettre en œuvre les principales opérations sur les tableaux directement dans la console JavaScript.

  </head>
  <body>

script.js

```js
// 1. Créer un tableau de fruits
let fruits = ["pomme", "banane", "cerise"];
console.log("Tableau initial :", fruits);

// 2. Ajouter et supprimer
fruits.push("orange");
console.log("Après push :", fruits);

fruits.pop();
console.log("Après pop :", fruits);

// 3. Modifier un élément
fruits[1] = "kiwi";
console.log("Après modification :", fruits);

// 4. Ajouter au début et supprimer le premier
fruits.unshift("fraise");
console.log("Après unshift :", fruits);

fruits.shift();
console.log("Après shift :", fruits);

// 5. Utiliser splice pour insérer des éléments
fruits.splice(1, 0, "ananas");
console.log("Après splice :", fruits);

// 6. Parcours du tableau
console.log("Boucle for :");
for (let i = 0; i < fruits.length; i++) {
  console.log(i, fruits[i]);
}

// 7. Tableau d’objets
let produits = [
  { nom: "Stylo", prix: 5 },
  { nom: "Cahier", prix: 15 },
  { nom: "Crayon", prix: 3 },
];

console.log("Liste des produits :");
produits.forEach((p) => console.log(`${p.nom} → ${p.prix} DH`));
```

💡 Bonus : ajoute un nouveau livre dans le tableau à l’aide de push().

## 6. 🧾 Résumé et points-clés

Un tableau est une collection ordonnée d’éléments accessibles par indice.

Les méthodes (push, pop, splice, map, filter, etc.) permettent de manipuler facilement les données.

Un tableau d’objets permet de gérer des données structurées (produits, utilisateurs, livres…).

Les tableaux sont la base de nombreuses structures utilisées dans le développement web et les API.
