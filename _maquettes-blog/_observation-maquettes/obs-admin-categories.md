# Observation de la maquette : admin-categories.html

## 1. Description de la page
Cette page affiche le tableau de gestion des catégories du blog.

## 2. Ce que l'apprenant doit observer
L'apprenant doit repérer (similaire à la gestion des articles) :
* **Le bouton d'ajout** : "Ajouter une catégorie".
* **Le tableau de données** : Avec les colonnes utiles (Nom de la catégorie).
* **Les boutons d'actions par ligne** : "Modifier" et "Supprimer" pour chaque catégorie.

## 3. Lien avec les Unités d'Apprentissage (UA) et Tutoriels
* **[UA.111.11 / T.111.111] Espaces du Blog :** Appartient à l'**Espace Administration**.
* **[UA.111.13 / T.111.131] Actions :** L'apprenant liste les actions :
  - Consulter la liste des catégories.
  - Cliquer sur Ajouter une catégorie.
  - Cliquer sur Modifier une catégorie.
  - Cliquer sur Supprimer une catégorie.
* **[UA.111.13 / T.111.132] Organisation :** L'apprenant regroupe ces actions sous l'entité **Catégories**.
