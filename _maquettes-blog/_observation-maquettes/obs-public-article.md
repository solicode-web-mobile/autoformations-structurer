# Observation de la maquette : public-article.html

## 1. Description de la page
C'est la page qui affiche le contenu détaillé d'un article spécifique du Blog. 

## 2. Ce que l'apprenant doit observer
L'apprenant doit repérer :
* **Le menu commun** : Toujours présent pour la navigation (souvent appelé Layout ou Master Page).
* **Les éléments de l'article** : Le titre complet, la date de publication, le nom de l'auteur, l'image principale et le texte complet.
* **La navigation contextuelle** : Le bouton de retour ou le logo pour revenir à l'accueil.

## 3. Lien avec les Unités d'Apprentissage (UA) et Tutoriels
* **[UA.111.11 / T.111.111] Espaces du Blog :** L'apprenant associe cette page à l'**Espace Public**.
* **[UA.111.11 / T.111.112] Acteurs :** L'apprenant associe cette page au **Visiteur**.
* **[UA.111.12 / T.111.121] Actions :** L'apprenant repère l'action :
  - Lire/Consulter le détail d'un article complet.
