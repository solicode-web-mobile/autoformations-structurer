Découvrir **HTML, CSS, JavaScript et PHP** et comprendre simplement leur rôle dans le Web.

**Prérequis** : Un navigateur Web et une connexion Internet.

# Partie 1 — Théorie

## 1.1. HTML — Structurer la page

**HTML** permet de créer le contenu et la structure d’une page Web.

**Exemple :** afficher un nom et un prénom.

```html
<h1>Prénom Nom</h1>
```

## 1.2. CSS — Présenter la page

**CSS** permet de modifier l’apparence d’une page Web.

**Exemple :** changer la couleur ou la taille d’un texte.

```css
h1 {
  color: blue;
}
```

## 1.3. JavaScript — Ajouter des actions

**JavaScript** permet d’ajouter des actions à une page Web.

**Exemple :** afficher un message après un clic.

```javascript
alert("Bonjour");
```

Les apprenants qui connaissent déjà JavaScript peuvent préparer un exemple simple pour le présenter.

## 1.4. PHP — Traiter les données

**PHP** est utilisé sur le serveur pour traiter des données.

**Exemple :** traiter les données envoyées par un formulaire.

Les apprenants qui connaissent déjà PHP peuvent préparer un exemple simple pour le présenter.

## 1.5. À retenir

* **HTML** → contenu et structure.
* **CSS** → apparence.
* **JavaScript** → actions.
* **PHP** → traitement des données sur le serveur.

# 4. Glossaire

* **HTML** : langage utilisé pour créer le contenu et la structure d’une page Web.
* **CSS** : langage utilisé pour définir l’apparence d’une page Web.
* **JavaScript** : langage utilisé pour ajouter des actions à une page Web.
* **PHP** : langage utilisé sur le serveur pour traiter des données.
* **Serveur** : ordinateur qui fournit des données ou des services.
