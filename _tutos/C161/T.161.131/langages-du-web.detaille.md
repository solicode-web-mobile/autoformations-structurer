Découvrir **HTML, CSS, JavaScript et PHP** et comprendre simplement le rôle de chacun dans le Web.

**Prérequis** : Un navigateur Web et une connexion Internet.

# Partie 1 — Théorie

## 1.1. HTML — Structurer la page

**HTML** est utilisé pour créer le contenu d’une page Web.

Il permet de placer les éléments de la page, comme un titre, un texte ou un nom.

**Exemple :** afficher votre prénom et votre nom sur une page Web.

```html
<h1>Prénom Nom</h1>
```

HTML permet donc de définir ce qui doit apparaître dans la page.

## 1.2. CSS — Présenter la page

**CSS** permet de modifier l’apparence des éléments créés avec HTML.

Il peut modifier, par exemple, la couleur, la taille ou l’alignement d’un texte.

**Exemple :**

```css
h1 {
  color: blue;
}
```

HTML crée le contenu. CSS permet de le présenter.

## 1.3. JavaScript — Ajouter des actions

**JavaScript** permet d’ajouter des actions et des comportements à une page Web.

Il peut, par exemple, réagir à un clic ou afficher un message.

**Exemple :**

```javascript
alert("Bonjour");
```

Cet exemple affiche un message dans le navigateur.

Les apprenants qui connaissent déjà JavaScript peuvent préparer un exemple simple pour le présenter au groupe.

## 1.4. PHP — Traiter les données

**PHP** est un langage utilisé sur le serveur.

Il peut traiter des données et produire un contenu dynamique pour une page Web.

**Exemple :** PHP peut recevoir les données d’un formulaire et les traiter sur le serveur.

Les apprenants qui connaissent déjà PHP peuvent préparer un exemple simple pour le présenter au groupe.

## 1.5. À retenir

* **HTML** → crée le contenu et la structure.
* **CSS** → modifie l’apparence.
* **JavaScript** → ajoute des actions.
* **PHP** → traite des données sur le serveur.

HTML et CSS sont utilisés directement pour réaliser la première page de cette activité.

JavaScript et PHP sont ici découverts à travers des exemples. Leur reproduction n’est pas demandée aux débutants.

# Partie 2 — Pratique

## 2.1. Réaliser une première page Web

### Étape 1 — Créer la page

Créez une page Web simple avec **HTML**.

Affichez votre prénom et votre nom.

Exemple :

```html
<h1>Prénom Nom</h1>
```

Le but est simplement d’obtenir un contenu visible dans le navigateur.

### Étape 2 — Ajouter le style

Ajoutez **CSS** pour modifier l’apparence de votre prénom et de votre nom.

Exemple :

```css
h1 {
  color: blue;
}
```

Vous pouvez modifier la couleur ou la taille du texte.

Ne cherchez pas à créer une page complexe.

**Résultat attendu :**

Une page Web affiche votre **prénom et votre nom** avec une présentation simple.

## 2.2. Préparer les exemples JavaScript et PHP

### Étape 3 — Préparer un exemple JavaScript

Si vous avez déjà étudié **JavaScript**, préparez un exemple simple.

L’exemple doit montrer une action réalisée par JavaScript.

Présentez ensuite l’exemple aux autres apprenants.

Les apprenants qui ne connaissent pas JavaScript observent l’exemple et identifient simplement son rôle.

### Étape 4 — Préparer un exemple PHP

Si vous avez déjà étudié **PHP**, préparez un exemple simple.

L’exemple doit montrer une action réalisée par PHP sur le serveur.

Présentez ensuite l’exemple aux autres apprenants.

Les apprenants qui ne connaissent pas PHP observent l’exemple et identifient simplement son rôle.

**Résultat attendu :**

Vous pouvez expliquer simplement le rôle de **HTML, CSS, JavaScript et PHP**.

## 2.3. Créer la présentation

### Étape 5 — Créer une présentation

Créez une présentation avec **Google Slides**.

Utilisez **3 slides maximum**.

Présentez :

* **HTML** : contenu et structure ;
* **CSS** : apparence ;
* **JavaScript** : actions ;
* **PHP** : traitement des données.

Ajoutez un exemple simple pour chaque technologie.

Les exemples JavaScript et PHP peuvent être ceux préparés à l’étape précédente.

### Étape 6 — Partager la présentation

Cliquez sur **Partager**.

Sélectionnez :

**Toute personne disposant du lien**

Choisissez **Lecteur**.

Cliquez sur **Copier le lien**.

### Étape 7 — Présenter

Partagez le lien selon la consigne donnée.

Présentez votre travail selon la modalité prévue par **Active LMS**.

Expliquez avec vos propres mots le rôle des quatre technologies.

**Résultat attendu :**

Vous pouvez expliquer simplement le rôle de **HTML, CSS, JavaScript et PHP**.

# 3. Bilan

**Vous avez réalisé :** une première page Web avec HTML et CSS et une présentation sur HTML, CSS, JavaScript et PHP.

**Vous savez maintenant :** expliquer simplement le rôle de HTML, CSS, JavaScript et PHP et distinguer leur utilisation dans une réalisation Web.

# 4. Glossaire

* **HTML** : langage utilisé pour créer le contenu et la structure d’une page Web.
* **CSS** : langage utilisé pour définir l’apparence d’une page Web.
* **JavaScript** : langage utilisé pour ajouter des actions à une page Web.
* **PHP** : langage utilisé sur le serveur pour traiter des données.
* **Serveur** : ordinateur qui fournit des données ou des services.
* **Navigateur Web** : logiciel utilisé pour ouvrir et consulter des pages Web.
