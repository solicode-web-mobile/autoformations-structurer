Découvrir **HTML, CSS, JavaScript et PHP** et comprendre simplement leur rôle dans le Web.

**Prérequis** : Un navigateur Web et une connexion Internet.

# Partie 1 — Théorie

## 1.1. HTML — Structurer la page

**HTML** permet de créer le contenu d’une page Web.

**Exemple :** afficher un nom et un prénom.

## 1.2. CSS — Présenter la page

**CSS** permet de modifier l’apparence du contenu.

**Exemple :** changer la couleur ou la taille du nom.

## 1.3. JavaScript — Ajouter des actions

**JavaScript** permet d’ajouter des actions à une page Web.

**Exemple :** afficher un message après un clic.

## 1.4. PHP — Traiter les données

**PHP** permet de traiter des données sur le serveur.

**Exemple :** traiter les données d’un formulaire.

## 1.5. À retenir

* **HTML** → contenu et structure.
* **CSS** → apparence.
* **JavaScript** → actions.
* **PHP** → traitement des données.

# 4. Glossaire

* **HTML** : langage qui crée le contenu d’une page Web.
* **CSS** : langage qui définit l’apparence d’une page Web.
* **JavaScript** : langage qui ajoute des actions à une page Web.
* **PHP** : langage utilisé sur le serveur pour traiter des données.
* **Serveur** : ordinateur qui fournit des données ou des services.
