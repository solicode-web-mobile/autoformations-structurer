

## 2. Règles des Tutos dans une UA

### 2.1. Respect de l’objectif de l’UA

Les tutoriels d’une UA doivent respecter :

**UA → notions → réalisation → livrable**

Ne pas introduire une solution ou une notion qui dépasse le travail prévu par l’UA.

### 2.2. Construction par l’apprenant

Lorsque l’UA demande à l’apprenant de construire une solution, le tutoriel ne doit pas donner cette solution.

Le tutoriel peut fournir :

* les notions nécessaires ;
* le problème ;
* les données ;
* le résultat attendu ;
* des indications d’organisation du travail.

L’apprenant doit construire lui-même le raisonnement et la solution.

### 2.3. Tutoriels d’algorithmique

Pour une UA d’algorithmique, ne pas donner :

* la solution de l’algorithme ;
* le pseudo-code ;
* les étapes logiques de résolution ;
* les conditions qui révèlent directement la solution ;
* une trace déjà résolue ;
* du code qui réalise tout ou partie de la solution attendue.

Le tutoriel doit expliquer **le problème**, pas **sa résolution**.

### 2.4. Partie théorique

Pour les tutoriels d’algorithmique, la partie théorique doit principalement suivre cette logique :

**Rappel JavaScript → Présentation du problème**

Le rappel JavaScript présente uniquement les notions utiles.

Pour un travail sur les tableaux, rappeler notamment :

* déclarer un tableau ;
* lire un élément ;
* écrire ou modifier un élément ;
* utiliser un indice ;
* utiliser `length` ;
* parcourir un tableau avec `for`, lorsque nécessaire.

La présentation du problème doit donner :

* les données ;
* le travail demandé ;
* le résultat attendu.

Elle ne doit pas donner la méthode de résolution ni un indice direct vers l’algorithme.

### 2.5. Partie pratique

La pratique doit donner les informations nécessaires pour organiser le travail :

* nom du fichier à créer ;
* données de départ ;
* organisation générale du travail ;
* action attendue ;
* résultat attendu.

L’apprenant construit lui-même la solution.

### 2.6. Test et débogage

Lorsque le débogage est prévu, demander à l’apprenant de :

**tester et déboguer ligne par ligne.**

Ne pas fournir une procédure détaillée indiquant :

* comment commencer le débogage ;
* où placer le premier point d’arrêt ;
* quelles commandes utiliser ;
* quelle séquence suivre pour déboguer.

Le tutoriel indique **ce que l’apprenant doit faire**, mais ne transforme pas le débogage en solution guidée.

### 2.7. Règle fondamentale

> **Le tutoriel fournit le cadre, les connaissances et les données nécessaires. L’apprenant réalise lui-même le raisonnement, la solution, les tests et les corrections.**
