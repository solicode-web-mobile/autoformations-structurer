À Solicode, vous apprenez surtout **en faisant** : vous lisez, pratiquez, cherchez, réalisez et expliquez.

## 1. Tutoriels — Apprendre les bases

Les tutoriels permettent d’apprendre en **autoformation**.

**Lire → Comprendre → Reproduire → Tester**

Un **Live Coding** peut ensuite permettre d’expliquer une réalisation. Le formateur vérifie la compréhension et complète si nécessaire.

## 2. Labs — Chercher et expérimenter

Dans un Lab, vous recherchez une solution dans **Internet, la documentation ou des exemples**.

**Chercher → Tester → Trouver une solution**

Le Lab développe votre autonomie.

## 3. Prototype — S’entraîner

Le Prototype est une **petite réalisation avant le projet complet**.

**Tutoriel** → apprendre une réalisation.

**Prototype** → réutiliser cette réalisation dans un nouveau contexte.

Le Prototype permet de pratiquer, trouver les difficultés et corriger les erreurs.

## 4. Projet Fil Rouge — Construire

Le Projet Fil Rouge est construit progressivement par **Sprint**.

**Page d’accueil → Page détail → Catégories → Articles**

Vous réutilisez les acquis des Tutoriels, Labs et Prototype.

## 5. Présentation — Expliquer

Vous expliquez votre travail :

**Ce que j’ai appris → Ce que j’ai réalisé → Comment je l’ai réalisé**

## 6. À retenir

**Tutoriel** → apprendre.
**Lab** → chercher et expérimenter.
**Prototype** → s’entraîner et adapter.
**Projet Fil Rouge** → réutiliser et construire.
**Présentation** → expliquer et montrer.

**Apprendre → Pratiquer → Chercher → S’entraîner → Construire → Expliquer**

## 7. Travail à faire

Dans **Google Slides**, créez un schéma :

**Tutoriels → Labs si nécessaire → Prototype → Projet Fil Rouge → Présentation**

Pour chaque étape, ajoutez **une phrase sur ce que vous faites et ce que vous apprenez**.

Présentez votre schéma selon la consigne donnée.

**Résultat attendu :** vous savez expliquer comment vous allez apprendre et travailler pendant une Session à Solicode.
