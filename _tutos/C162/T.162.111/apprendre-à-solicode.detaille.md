À Solicode, vous apprenez surtout **en faisant**. Vous découvrez une notion, vous la mettez en pratique, vous cherchez des solutions lorsque cela est nécessaire, puis vous réalisez et expliquez votre travail.

## 1. Tutoriels — Apprendre les bases

Les tutoriels permettent d’apprendre progressivement les notions nécessaires à une réalisation.

Vous commencez par observer un exemple. Vous cherchez ensuite à comprendre comment il fonctionne, puis vous reproduisez la réalisation proposée.

**Lire → Comprendre → Reproduire → Tester**

Le tutoriel est principalement réalisé en **autoformation**. Vous avancez à votre rythme et vous vérifiez votre résultat.

Selon l’activité, un **Live Coding** peut être prévu. Dans ce cas, un apprenant explique sa réalisation à partir de son travail. Le formateur vérifie la compréhension et complète les explications si nécessaire.

## 2. Labs — Chercher et expérimenter

Lorsqu’un **Lab** est prévu, vous ne recevez pas toujours directement la solution.

Vous recherchez une information ou une méthode dans **Internet, la documentation ou des exemples**. Vous testez ensuite ce que vous avez trouvé.

**Chercher → Tester → Trouver une solution**

Le Lab vous apprend à chercher une réponse lorsque vous rencontrez une difficulté. Cette capacité est importante dans le travail d’un développeur.

## 3. Prototype — S’entraîner

Le **Prototype** est une petite réalisation qui vient après les apprentissages de base.

Vous reprenez une notion ou une technique déjà étudiée et vous l’utilisez dans une nouvelle réalisation. Le contexte change, mais les connaissances déjà acquises peuvent être réutilisées.

**Apprendre → Réutiliser → Adapter → Corriger**

Le Prototype permet de vérifier si vous savez utiliser ce que vous avez appris sans simplement copier le tutoriel. Il permet aussi de trouver les difficultés avant de passer au projet complet.

## 4. Projet Fil Rouge — Construire

Le **Projet Fil Rouge** est construit progressivement pendant les **Sprints**.

Vous utilisez les connaissances acquises dans les Tutoriels, les Labs et le Prototype pour réaliser une partie du projet.

**Tutoriels → Labs si nécessaire → Prototype → Projet Fil Rouge**

Chaque nouvelle réalisation s’appuie sur les apprentissages précédents. Vous construisez ainsi le projet étape par étape.

## 5. Présentation — Expliquer

Une activité peut prévoir une **présentation**, mais la modalité finale dépend de ce qui est défini dans **Active LMS**.

Selon l’activité, vous pouvez devoir présenter votre travail ou expliquer votre réalisation dans une autre modalité, comme un **Live Coding**.

Lorsque la présentation est prévue, vous expliquez simplement :

**Ce que j’ai appris → Ce que j’ai réalisé → Comment je l’ai réalisé**

Expliquer votre travail permet de montrer ce que vous avez compris et de prendre du recul sur votre réalisation.

## 6. À retenir

Chaque activité a un rôle différent :

**Tutoriel** → apprendre et reproduire.
**Lab** → chercher et expérimenter.
**Prototype** → s’entraîner et adapter.
**Projet Fil Rouge** → réutiliser et construire.
**Présentation** → expliquer et montrer.

La progression peut être résumée ainsi :

**Apprendre → Pratiquer → Chercher → S’entraîner → Construire → Expliquer**

Toutes les activités ne demandent pas la même modalité. La réalisation et la modalité d’évaluation ou de restitution sont celles prévues par **Active LMS**.

## 7. Travail à faire

Dans **Google Slides**, créez un schéma qui montre les principales étapes d’une Session :

**Tutoriels → Labs si nécessaire → Prototype → Projet Fil Rouge → Présentation**

Pour chaque étape, ajoutez **une phrase sur ce que vous faites et ce que vous apprenez**.

Utilisez des formes, des flèches et un texte court pour rendre le schéma facile à comprendre.

Présentez votre schéma selon la modalité prévue par **Active LMS**.

**Résultat attendu :**

Vous pouvez expliquer simplement comment se déroule une Session à Solicode et le rôle de chaque étape.
