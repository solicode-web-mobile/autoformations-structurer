objectif: >
  Combiner plusieurs traitements algorithmiques simples afin de résoudre
  un problème nécessitant plusieurs opérations successives.

  À partir d’un problème composé de plusieurs étapes, décomposer le traitement
  en opérations simples, les organiser dans un ordre logique et les combiner
  afin de produire un algorithme complet permettant d’obtenir le résultat attendu.
notions:

 -"Variables"
 -"Conditions"
 -"Boucles"
 -"Tableaux"
 -"Fonctions"
 -"Ordonnancement des traitements"
 -"Algorithme complet"
livrable: >
  Algorithme complet combinant plusieurs traitements simples, accompagné
  d’exemples de tests permettant de vérifier chaque étape et le résultat final.
travail_a_faire: >
  Construire un algorithme JavaScript combinant plusieurs opérations sur un
  tableau, par exemple parcourir les valeurs, rechercher une valeur particulière,
  calculer un résultat et trier les données, puis tester l’ensemble du traitement.
