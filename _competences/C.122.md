---
title: "Construire l’interface"
layout: competences
code: "C.122"
niveau: "N1"
mission: "M2"
objectif: >
  Transformer une conception Web existante en interface fonctionnelle et interactive, 
  puis corriger les problèmes simples de structure, d’affichage, de comportement 
  ou d’interaction. Interpréter une conception, structurer avec HTML, appliquer une 
  présentation CSS, afficher les informations nécessaires, sélectionner et manipuler 
  les éléments, réagir aux actions utilisateur, modifier dynamiquement l’interface, 
  observer, corriger et vérifier.
competence: >
  Transformer une conception Web en interface fonctionnelle, corriger les problèmes 
  simples et vérifier le comportement attendu.
livrable: >
  Interface Web fonctionnelle et corrigée comprenant une structure HTML cohérente, 
  une présentation CSS lisible, des composants adaptés et des interactions 
  JavaScript vérifiées.
