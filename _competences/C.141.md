---
title: "Mettre une application en service localement"
layout: competences
code: "C.141"
niveau: "N1"
mission: "M4"
objectif: >
  Mettre une application Web en service dans un environnement local connu à partir 
  d’une procédure existante et vérifier son accessibilité et son fonctionnement. 
  Le N1 reste centré sur un déploiement local guidé sans conception d’infrastructure 
  ni administration avancée.
competence: >
  Mettre une application Web en service dans un environnement local connu en suivant 
  une procédure définie. Identifier les prérequis, vérifier le serveur Web, PHP et 
  la base de données, placer les fichiers, appliquer les paramètres, démarrer les 
  services, accéder à l’application, vérifier son fonctionnement, appliquer une 
  correction connue et signaler un problème dépassant son autonomie.
livrable: >
  Application Web locale mise en service comprenant l’environnement préparé, 
  les prérequis vérifiés, l’application installée, les paramètres appliqués, 
  les services démarrés, l’accès local validé, le fonctionnement vérifié et 
  les corrections élémentaires réalisées lorsque nécessaire.
