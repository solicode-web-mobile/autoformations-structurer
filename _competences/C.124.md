---
title: "Exploiter les données"
layout: competences
code: "C.124"
niveau: "N1"
mission: "M2"
objectif: >
  Exploiter les données d’une base relationnelle pour faire fonctionner les 
  fonctionnalités de l’application, puis corriger les erreurs simples liées 
  à leur récupération ou utilisation. Identifier les tables, clés et relations, 
  écrire des requêtes SQL simples (sélectionner, filtrer, trier), récupérer 
  des données liées, exploiter les résultats en PHP, alimenter une fonctionnalité, 
  identifier et corriger une erreur simple, puis vérifier le résultat.
competence: >
  Retrouver les données nécessaires, les exploiter dans une fonctionnalité, 
  corriger un problème simple et vérifier la conformité du résultat au besoin.
livrable: >
  Données exploitées par l’application comprenant les requêtes SQL du périmètre, 
  les résultats vérifiés, leur exploitation côté serveur, les corrections 
  simples et la vérification finale.
